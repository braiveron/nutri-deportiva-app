# 🍎 NutriSport - Plataforma de Gestión Fitness

NutriSport es una aplicación web integral diseñada para deportistas y personas que buscan optimizar su rendimiento a través de la nutrición y el entrenamiento. El proyecto combina una lógica de cálculo precisa con una interfaz moderna y profesional.

## 🚀 Características Principales

* **Calculadora Nutricional Inteligente:** Algoritmo personalizado para determinar requerimientos de proteínas y macronutrientes según objetivos (ganancia muscular, mantenimiento o pérdida de grasa).
* **Gestión de Estados en Tiempo Real:** Interfaz reactiva que responde instantáneamente a las entradas del usuario.
* **Diseño High-End:** Interfaz estética, limpia y responsiva construida con Tailwind CSS, enfocada en la experiencia del usuario (UX).
* **Arquitectura Escalable:** Código modularizado para facilitar la implementación de nuevas funcionalidades (como tracking de progreso o bases de datos de alimentos).

## 🛠️ Tecnologías Utilizadas

* **Frontend:** React.js
* **Estilos:** Tailwind CSS
* **Lógica de Estado:** React Hooks (`useState`, `useEffect`)
* **Iconografía:** Lucide React / Heroicons
* **Despliegue:** Vercel / SupaBase / Render

## 🧠 Desafíos Técnicos Resueltos

* **Lógica de Negocio:** Implementación de funciones puras para el cálculo de macros basadas en variables antropométricas.
* **Componentes Controlados:** Manejo de formularios complejos garantizando la integridad de los datos (parseo de strings a números, validaciones).
* **Optimización UI:** Uso de transiciones y estados de carga (`loading`) para mejorar el feedback visual.
