# 🍎 NutriSport Platform

NutriSport es una plataforma integral de alto rendimiento diseñada para la gestión nutricional y el seguimiento de entrenamiento. Este proyecto nace de la intersección entre la disciplina deportiva y la ingeniería de software, ofreciendo una experiencia de usuario fluida respaldada por inteligencia artificial.

## 🚀 Características Principales

* **Recomendaciones con IA:** Integración de modelos generativos para el análisis y sugerencia de planes personalizados según objetivos físicos.
* **Calculadora de Macros Pro:** Algoritmos precisos para el desglose calórico basados en variables antropométricas.
* **Gestión de Pagos Integrada:** Sistema preparado para suscripciones y transacciones mediante pasarelas líderes en Latam.
* **Interfaz High-End:** Diseño minimalista, responsivo y orientado a la performance construido con Tailwind CSS.

## 🛠️ Tecnologías Utilizadas

### Frontend & UI
* **Framework:** React.js
* **Estilos:** Tailwind CSS
* **Estado:** React Hooks & Context API

### Backend & Inteligencia Artificial
* **Runtime:** Node.js con **Express.js (v5)**
* **IA Generativa:** Integración avanzada con **Google Generative AI (Gemini)** y **Groq SDK**.
* **Pasarelas de Pago:** Implementación de SDKs de **Mercado Pago**.

### Infraestructura & Datos
* **Base de Datos:** **PostgreSQL** administrado vía **Supabase**.
* **Gestión de Datos:** Arquitectura híbrida usando `supabase-js` y `pg` nativo.
* **Despliegue:** Vercel (Frontend) y Render (Backend).

## 🧠 Desafíos Técnicos Resueltos

* **Implementación de IA:** Configuración de prompts y manejo de respuestas asíncronas de modelos LLM para integrarlos en la lógica de usuario.
* **Seguridad en Pagos:** Manejo de Webhooks y flujos de aprobación de transacciones financieras.
* **Arquitectura de Datos:** Diseño de esquemas relacionales eficientes para el manejo de perfiles de usuario y registros históricos de nutrición.
